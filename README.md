# coolapk-agent-tool

给 AI Agent / 程序调用的酷安内容查询工具。命令行输出 JSON,覆盖搜索、话题、图文详情、评论、图片下载。

## 特性

- **JSON 输出**:单条命令一次输出,方便 AI Agent 或脚本直接消费
- **默认精确搜索**(`isStrict=1`):减少无关结果,更适合"找确切内容"
- **自动翻页**:`--limit 30` 会自动翻页凑满 30 条,而不是只给第一页
- **token 自动续签**:token 过期(实测有效期 24h)自动离线签发,不用重新抓包;内容接口无需账号登录
- **省 token 模式**:`--lite` 实测搜索省约 40%、评论省约 35%(适合喂给 AI)
- **图片本地化**:`images` 把图片存到本地,由 AI 自己查看(不做 OCR)

## 快速开始

### 方式一:exe(无需安装 Python)

    酷安agent.exe check
    酷安agent.exe search "小米解锁bl" --limit 10 --lite

> 首次运行 Windows 可能提示 SmartScreen(未签名程序):点"更多信息" → "仍要运行"。

### 方式二:从源码运行

需要 Python 3.9+:

    pip install requests bcrypt
    python 酷安agent.py search "关键词" --lite

## 命令一览

| 命令 | 说明 |
|---|---|
| `check` | 检查凭证有效性(含离线续签能力) |
| `search <关键词>` | 直接搜索(默认精确匹配) |
| `topics <关键词>` | 找相关话题 |
| `topic <话题名>` | 列出话题下的内容 |
| `feed <动态ID>` | 取图文/动态详情(长文全文) |
| `comments <动态ID>` | 取评论(含楼中楼) |
| `images <动态ID>` | 把图片下载到本地 |
| `token` | 现场签发一个可用 token(离线,不用抓包) |
| `import-har <路径>` | 从 HAR/zip 抓包导入自定义凭证 |

常用参数:`--limit` 条数、`--page` 页码、`--lite` 精简输出、`--max-text` 正文截断长度。

## 凭证说明

- 工具自带匿名凭证,开箱即用;内容类接口不需要账号登录即可使用
- 如需使用自己的凭证(更换设备码/提高稳定性),抓包后用
  `酷安agent.exe import-har 抓包.har` 导入,会写入程序同目录的 `config.json`
- `config.json` 内含凭证,请勿公开分享

## 输出与文件

- 所有命令输出 JSON(单行),成功时 `"ok": true`
- `images` 下载的图片保存在程序同目录的 `_images/<动态ID>/` 下
